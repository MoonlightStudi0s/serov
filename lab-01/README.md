# Практическая работа № 1. Установка ОС «РОСА» на VMware Workstation

Отчёт об установке ОС «РОСА Фреш 13.2» на виртуальную машину VMware Workstation Pro 26H1
(отработка навыков установки ОС на базе ядра Linux; дистрибутив ведёт происхождение от Red Hat,
установщик — Anaconda).

## Структура

```
lab-01/
├── screenshots/    исходные 38 скриншотов хода работы (1.jpg … 38.jpg)
├── report/         готовый отчёт
│   ├── Отчёт_ЛР1_Установка_РОСА_на_VMware.docx
│   └── Отчёт_ЛР1_Установка_РОСА_на_VMware.pdf
└── build/          скрипты сборки отчёта
    ├── content.py        текст отчёта и подписи к рисункам
    ├── make_report.py    генерация DOCX и PDF
    ├── requirements.txt
    └── fonts/            шрифты Tinos (метрически совместимы с Times New Roman)
```

## Состав отчёта

1. Цель работы
2. Задание
3. Используемое программное обеспечение и параметры виртуальной машины (таблица 1)
4. Краткие теоретические сведения (особенности дистрибутивов семейства Red Hat)
5. Ход выполнения работы
   - 5.1 Создание виртуальной машины (рисунки 1–15)
   - 5.2 Установка операционной системы (рисунки 16–29)
   - 5.3 Первичная загрузка и вход в систему (рисунки 30–34)
   - 5.4 Настройка сети и оформления рабочего стола (рисунки 35–38)
6. Проблемы, возникшие при выполнении работы, и способы их решения
7. Вывод
- Список использованных источников

## Оформление

Отчёт оформлен по правилам, близким к ГОСТ 7.32-2017: Times New Roman 14 пт, межстрочный
интервал 1,5, абзацный отступ 1,25 см, выравнивание по ширине, поля 30/15/20/20 мм,
нумерация страниц внизу по центру (титульный лист не нумеруется), подписи к рисункам по
центру, содержание с номерами страниц.

## Правка и пересборка

Весь текст отчёта и подписи к рисункам находятся в `build/content.py`. После правки
пересобирать оба файла одной командой:

```bash
python3 -m venv .venv && .venv/bin/pip install -r build/requirements.txt
.venv/bin/python build/make_report.py
```

Требуется Python 3.9+; LibreOffice и Microsoft Office для сборки не нужны.

## Шрифты

`build/fonts/Tinos-*.ttf` — свободный шрифт Tinos (лицензия Apache 2.0), метрически совместимый
с Times New Roman: в PDF он используется вместо Times New Roman, в DOCX указан сам
Times New Roman (подставляется системой при открытии в Word).
