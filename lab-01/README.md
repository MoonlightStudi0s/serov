# Практическая работа № 1. Установка ОС «РОСА» на VMware Workstation

Отчёт об установке ОС «РОСА Фреш 13.2» на виртуальную машину VMware Workstation Pro 26H1
(отработка навыков установки ОС на базе ядра Linux; дистрибутив ведёт происхождение от Red Hat,
установщик — Anaconda).

Оформление — 1:1 по образцам из `examples/` (три отчёта однокурсников, сделанных
в LibreOffice) и по «Краткой выписке из ГОСТ 7.32-2017 "Структура и правила
оформления"» из той же папки: Times New Roman 14 пт, полуторный интервал,
выравнивание по ширине, абзацный отступ 1,25 см, поля 30/15/20/20 мм, нумерация
страниц внизу по центру тем же шрифтом (титульный лист входит в нумерацию,
но номер на нём не проставляется). Титульный лист — по образцу «Лаба 2.odt» /
«Gentoo.odt»: «Колледж Научно-Технологического Университета Сириус», линия из
подчёркиваний, «ПРАКТИЧЕСКАЯ РАБОТА № 1.», «по дисциплине…», «на тему…», блок
«Выполнил/Принял» справа, внизу по центру «IT-Колледж «Сириус», 2026».
РЕФЕРАТ — по образцу: «Пояснительная записка NN c., NN рис., …», ключевые слова
прописными. После каждого заголовка и подзаголовка, вокруг рисунков и подписей,
до и после таблицы — пустая строка; РЕФЕРАТ, СОДЕРЖАНИЕ, ВВЕДЕНИЕ, ЗАКЛЮЧЕНИЕ,
СПИСОК ИСПОЛЬЗОВАННЫХ ИСТОЧНИКОВ — с нового листа, прописными по центру;
подпись рисунка — под рисунком после пустой строки; название таблицы — слева
над таблицей после пустой строки.

## Состав отчёта

1. Титульный лист по образцу примеров (группа и ФИО студента — прочерки для заполнения)
2. РЕФЕРАТ — «Пояснительная записка … c., … рис., … табл., … источников», ключевые слова
3. СОДЕРЖАНИЕ — с номерами страниц и отточием
4. ВВЕДЕНИЕ — актуальность, цель, задачи, объект и предмет работы
5. Основная часть:
   - 1 Операционная система «РОСА» и особенности установки дистрибутивов семейства Red Hat
     (подразделы 1.1–1.3)
   - 2 Используемое программное обеспечение и параметры виртуальной машины (таблица 1)
   - 3 Создание виртуальной машины (рисунки 1–15)
   - 4 Установка операционной системы (рисунки 16–29)
   - 5 Первичная загрузка и вход в систему (рисунки 30–34)
   - 6 Настройка сети и оформления рабочего стола (рисунки 35–38)
   - 7 Проблемы, возникшие при выполнении работы, и способы их решения
6. ЗАКЛЮЧЕНИЕ
7. СПИСОК ИСПОЛЬЗОВАННЫХ ИСТОЧНИКОВ (5 источников, на каждый есть ссылка [n] в тексте)

Каждый структурный элемент начинается с нового листа; разделы 1–7 идут подряд
(как требует выписка из ГОСТ); рисунки пронумерованы сквозной нумерацией,
после рисунка — пустая строка, затем подпись «Рисунок N – …»; название таблицы —
слева над таблицей.

## Правка и пересборка

Весь текст отчёта и подписи к рисункам находятся в `build/content.py`, параметры страницы
(поля, отступ, ширина рисунков) — в начале `build/make_report.py`. После правки пересобрать
все три файла одной командой (число страниц в реферате и номера страниц в содержании
пересчитываются автоматически):

```bash
python3 -m venv .venv && .venv/bin/pip install -r build/requirements.txt
.venv/bin/python build/make_report.py
```

Требуется Python 3.9+; LibreOffice и Microsoft Office для сборки не нужны.

Во всех трёх файлах ссылки в тексте вида «рисунок N» кликабельны: щелчок
(в Word — Ctrl+щелчок) переносит к подписи соответствующего рисунка
(гиперссылки на закладки в DOCX и ODT, внутренние ссылки в PDF).

Если в методичке указаны поля 25/20/20/20 мм и абзацный отступ 1,5 см, замените значения
в словаре `PAGE` файла `build/make_report.py` на `2.5`, `2.0`, `2.0`, `2.0` и `1.5`.

## Шрифты

`build/fonts/Tinos-*.ttf` — свободный шрифт Tinos (лицензия Apache 2.0), метрически совместимый
с Times New Roman: в PDF он используется вместо Times New Roman, в DOCX указан сам
Times New Roman (подставляется системой при открытии в Word).
