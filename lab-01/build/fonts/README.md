# Шрифты

`Tinos-Regular.ttf`, `Tinos-Bold.ttf`, `Tinos-Italic.ttf`, `Tinos-BoldItalic.ttf`

- Шрифт: **Tinos** (семейство Tinos, автор Steve Matteson)
- Источник: репозиторий Google Fonts, каталог `ofl/tinos`
  (https://github.com/google/fonts/tree/main/ofl/tinos)
- Лицензия: **Apache License 2.0** (https://www.apache.org/licenses/LICENSE-2.0)

Шрифт метрически совместим с Times New Roman (одинаковые ширины знаков), поэтому используется
при сборке PDF вместо Times New Roman — файлы PDF собираются без установки проприетарных
шрифтов Microsoft.
