Администрирование операционной системы Calculate Linux Desktop

Дисциплина Операционные системы и среды
Тема Администрирование Calculate Linux Desktop
Продолжительность 80 минут
Требования к ПО Виртуальная машина с установленной Calculate Linux Desktop, доступ к терминалу, учётная запись с правами sudo или root

Цель работы

Приобретение практических навыков по управлению обновлениями операционной системы, установке и удалению программного обеспечения, работе со службами и учётными записями пользователей в ОС Calculate Linux Desktop.

Теоретическая часть

Calculate Linux Desktop — российский дистрибутив на базе Gentoo, использующий систему Portage для управления пакетами. Ключевые особенности:

  • Rolling-release. Обновление системы без переустановки с помощью утилиты cl-update.
  • Бинарные пакеты. Большинство программ устанавливается быстро из бинарных репозиториев, но доступна и компиляция из исходников.
  • OpenRC. Система инициализации.
  • Утилиты Calculate. Собственный набор инструментов (cl-update, cl-useradd и др.) для администрирования.

Задание на лабораторную работу

  1. Обновление операционной системы. Убедитесь, что система и её репозитории находятся в актуальном состоянии. При необходимости выполните синхронизацию репозиториев и установите доступные обновления пакетов. Зафиксируйте перечень обновлённых компонентов.
  2. Управление программным обеспечением. Подберите и установите из репозитория любую консольную утилиту, ранее отсутствовавшую в системе (например, монитор процессов, файловый менеджер или сетевую утилиту). Убедитесь в её работоспособности. Затем удалите установленный пакет и очистите систему от оставшихся «осиротевших» зависимостей.
  3. Управление службами. Выберите любую установленную в системе службу. Определите её текущее состояние, выполните остановку и повторный запуск. Настройте автоматический запуск выбранной службы при загрузке системы, а затем отмените эту настройку.
  4. Управление учётными записями пользователей. Создайте двух новых пользователей: одного — с правами администратора (способного выполнять команды с повышением привилегий), второго — без таких прав. Задайте обоим пароли. Убедитесь, что разграничение прав работает: пользователь с правами администратора может выполнять привилегированные команды, а пользователь без прав — не может. При необходимости предоставьте пользователям доступ к типовым периферийным устройствам (звук, видео, съёмные носители).

Описание выполнения работы

Ниже приведён один из возможных вариантов выполнения каждого пункта задания. Допускается использование иных утилит и решений, приводящих к аналогичному результату.

Задание 1. Обновление системы (15 минут)

Обновление системы в Calculate Linux Desktop можно выполнять двумя способами: с помощью специализированной утилиты cl-update (рекомендуемый способ) и с помощью штатных средств Portage — утилиты emerge.

Способ 1. Обновление с помощью cl-update

  1. Откройте терминал. Выполните синхронизацию репозиториев без установки обновлений: 
    sudo cl-update --sync-only
    Дождитесь завершения. Эта команда обновляет дерево Portage и оверлеи, но не трогает установленные пакеты.
  2. Выполните полное обновление системы: 
    sudo cl-update
    Утилита автоматически:
    • выберет наиболее подходящее зеркало;
    • синхронизирует Portage и оверлеи;
    • рассчитает зависимости;
    • установит обновления;
    • удалит устаревшие зависимости.
  3. Зафиксируйте перечень обновлённых компонентов из итогового отчёта утилиты cl-update — он потребуется при оформлении отчёта.

Способ 2. Проверка и установка обновлений с помощью emerge

Штатные средства Portage позволяют как проверить наличие обновлений, так и установить их вручную. Этот способ удобен, когда требуется выборочное обновление отдельных пакетов или когда нужно понять, какие именно изменения будут внесены.

  1. Синхронизируйте дерево Portage (при необходимости): 
    sudo emerge --sync
  2. Проверьте, какие пакеты требуют обновления, без их фактической установки: 
    sudo emerge --pretend --update --deep --newuse @world
    Сокращённый вариант той же команды: 
    sudo emerge -p -u -D -N @world
    Флаг -p (--pretend) выводит план действий без их выполнения. Проанализируйте полученный список.
  3. Установите выявленные обновления: 
    sudo emerge --update --deep --newuse @world
    Сокращённый вариант: 
    sudo emerge -u -D -N @world
    При необходимости добавьте флаг -a для интерактивного подтверждения каждого действия.
  4. Удалите устаревшие зависимости, оставшиеся после обновления: 
    sudo emerge --depclean

Для повседневного администрирования в Calculate Linux Desktop предпочтительно использовать cl-update, поскольку она автоматически выполняет все перечисленные шаги. Однако понимание работы emerge необходимо для точечного управления отдельными пакетами.

Задание 2. Установка и удаление программного обеспечения (20 минут)

В качестве примера рассматривается установка и удаление утилиты htop — интерактивного монитора процессов. Студент может выбрать любую другую консольную утилиту из репозитория.

Порядок выполнения:

  1. Найдите программу в дереве пакетов: 
    eix htop
    В выводе обратите внимание на полное имя пакета (например, sys-process/htop) и доступные версии.
  2. Установите пакет: 
    sudo emerge -a sys-process/htop
    Флаг -a включает интерактивное подтверждение. Согласитесь с установкой, введя y.
  3. Запустите утилиту и убедитесь в работоспособности. Для выхода нажмите q.
  4. Удалите пакет: 
    sudo emerge --unmerge sys-process/htop
    Эта команда удаляет пакет, но не затрагивает его зависимости.
  5. Очистите систему от «осиротевших» зависимостей: 
    sudo emerge --depclean

Задание 3. Работа со службами (15 минут)

В Calculate Linux Desktop используется система инициализации OpenRC. В качестве примера рассматривается служба sshd (если она установлена); допускается выбрать любую другую службу.

Порядок выполнения:

  1. Просмотрите список запущенных служб: 
    sudo rc-status
    Вы увидите список сервисов и их состояние (started/stopped/crashed).
  2. Проверьте статус выбранной службы: 
    sudo rc-service sshd status
  3. Остановите и запустите службу: 
    sudo rc-service sshd stop
sudo rc-service sshd start
  4. Добавьте службу в автозапуск (на определённый runlevel, обычно default): 
    sudo rc-update add sshd default
    Для удаления из автозапуска: 
    sudo rc-update del sshd default

Задание 4. Создание и управление пользователями (20 минут)

В Calculate Linux Desktop права администратора предоставляются членством в группе wheel. Ниже создаются два пользователя: adminuser (с правами администратора) и simpleuser (без прав администратора).

Порядок выполнения:

  1. Переключитесь в консоль (если работаете в графике): Ctrl+Alt+F1. Войдите как root.
  2. Создайте пользователя с правами администратора: 
    useradd --create-home --groups users,wheel,audio,cdrom,video,usb,plugdev,games,scanner,lp,lpadmin adminuser
    • wheel — право на получение привилегий суперпользователя через su/sudo;
    • audio, video, cdrom — доступ к соответствующим устройствам;
    • plugdev — монтирование USB-устройств.
  3. Создайте пользователя без прав администратора (без группы wheel): 
    useradd --create-home --groups users,audio,cdrom,video,usb,plugdev,games,scanner,lp,lpadmin simpleuser
  4. Задайте пароли для обоих пользователей: 
    passwd adminuser
passwd simpleuser
    Введите пароль дважды для каждого (пароль не отображается при вводе).
  5. Проверьте создание пользователей и их членство в группах: 
    id adminuser
id simpleuser
    Убедитесь, что adminuser состоит в группе wheel, а simpleuser — нет.
  6. Проверьте разницу в правах. Войдите под simpleuser и попробуйте выполнить команду с sudo: 
    su - simpleuser
sudo ls /root
    Убедитесь, что доступ запрещён. Затем повторите под adminuser: 
    su - adminuser
sudo ls /root
    Убедитесь, что команда выполняется успешно.
  7. Вернитесь в графический сеанс: Alt+F7 (или exit для выхода из консоли root).

Требования к отчёту

Отчёт должен содержать:

  1. Титульный лист.
  2. Цель работы.
  3. Выполненные команды с краткими пояснениями.
  4. Скриншоты или вывод терминала, подтверждающие выполнение заданий.
  5. Ответы на вопросы для отчёта и контрольные вопросы.
  6. Вывод о проделанной работе.
