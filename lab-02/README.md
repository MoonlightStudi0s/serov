## Оформление

Для ODT сохранены исходные стили и макеты страницы из предоставленного образца:

- формат A4; поля: левое — 30 мм, правое — 15 мм, верхнее и нижнее — по 20 мм;
- Times New Roman, 14 пт, межстрочный интервал 1,5;
- выравнивание основного текста по ширине, абзацный отступ 1,25 см;
- заголовки и подписи к рисункам оформлены стилями образца;
- номер страницы находится снизу по центру, титульный лист не нумеруется.

В титульном листе указано имя, видимое на экране входа в ОС — **Лернер Владислав**. Поле группы оставлено пустым, так как оно не содержалось в исходных материалах: его можно заполнить непосредственно перед сдачей.

## Пересборка

Текст, подписи к рисункам и титульный лист находятся в `build/content.py`; скрипт `build/make_report.py` создаёт сразу ODT, DOCX и PDF. Для пересборки из корня репозитория:

```bash
python3 -m venv .venv
.venv/bin/pip install -r lab-02/build/requirements.txt
.venv/bin/python lab-02/build/make_report.py
```

Скрипт проверяет наличие всех 63 скриншотов и использует их строго по порядку. Для ODT он берёт параметры оформления непосредственно из `lab-01/examples/Лаба 2.odt`, поэтому файл можно безопасно открыть и продолжить редактирование в LibreOffice Writer.
