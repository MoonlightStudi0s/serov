# Практическая работа № 4. Установка Calculate Linux на виртуальную машину VMware Workstation

Отчёт о выполнении практической работы по дисциплине «Операционные системы и среды»:
создание виртуальной машины в VMware Workstation Pro 26H1, загрузка образа
Calculate Linux Desktop Xfce в режиме LiveDVD и установка системы средствами
установщика Calculate Console (система утилит Calculate).

Работа выполнялась на виртуальной машине `CalculateLinux` (8 виртуальных ядер,
16384 МБ оперативной памяти, диск SCSI 40 ГБ, сетевой адаптер NAT) с
установочного образа `cldx-20260916-x86_64.iso` — Calculate Linux Desktop Xfce
для архитектуры x86_64 (сборка 20260916).

Оформление — по главному шаблону (отчёт по ЛР3, файл
`lab-03/report/Отчёт_ЛР3_Настройка_загрузчика_GRUB2.odt`) и «Краткой выписке из
ГОСТ 7.32-2017» (файл `lab-01/examples/ОформлениеОтчета_Краткая_выписка_из_ГОСТ_с_Примерами.pdf`):
Times New Roman 14 пт, полуторный интервал, выравнивание по ширине, абзацный
отступ 1,25 см, поля 30/15/20/20 мм, номера страниц внизу по центру (титульный
лист без номера), заголовки подразделов разрежены на 3 пт, название таблицы —
слева над таблицей.

Титульный лист оформлен по образцу `lab-01/examples/Gentoo.odt`: название
колледжа по центру полужирным, черта из подчёркиваний, наименование работы,
дисциплина и тема по центру, блок «Выполнил / Принял» справа, внизу — колледж и
год. Подпись рисунка «Рисунок N – Название» вписана в само изображение (нижняя
белая полоса), а не вынесена отдельным абзацем под рисунком. Упоминания рисунков
в тексте («(рисунок N)») и записи СОДЕРЖАНИЯ (название и номер страницы) —
поля-перекрёстные ссылки: в LibreOffice они отображаются серым и по Ctrl+щелчку
переходят к рисунку или разделу.

## Состав отчёта

1. Титульный лист
2. РЕФЕРАТ — число страниц, рисунков, таблиц, источников и ключевые слова
3. СОДЕРЖАНИЕ — с номерами страниц и отточием
4. 1 Цель работы
5. 2 Краткие теоретические сведения (Calculate Linux и Gentoo, система утилит
   Calculate, LiveDVD и cl-install, шаги установщика, раздел /var/calculate,
   режимы сети VMware)
6. 3 Используемое окружение (таблица 1 — параметры виртуальной машины)
7. 4 Ход выполнения работы:
   - 4.1 Создание виртуальной машины (рисунки 1–14);
   - 4.2 Загрузка LiveDVD Calculate Linux (рисунки 15–17);
   - 4.3 Настройка параметров установки (рисунки 18–27, таблица 2 — разметка
     диска, таблица 3 — параметры установки);
   - 4.4 Запуск установки системы (рисунок 28);
8. 5 Вывод по работе
9. СПИСОК ИСПОЛЬЗОВАННЫХ ИСТОЧНИКОВ (7 источников, на каждый есть ссылка [n])

Рисунки 1–28 — скриншоты из `screenshots/` с подписями «Рисунок N – Название»,
вписанными в изображение (модуль `build/figures.py`). Каждый структурный элемент
начинается с нового листа; рисунки пронумерованы сквозной нумерацией; название
таблицы — слева над таблицей. В тексте упоминания рисунков оформлены как
перекрёстные ссылки разметкой `[[рисунок N]]` в `build/content.py`.

## Пересборка

```bash
python3 -m venv .venv && .venv/bin/pip install -r build/requirements.txt
.venv/bin/python build/make_report.py     # собрать ODT и рассчитать номера страниц
.venv/bin/python build/preview.py "report/Отчёт_ЛР4_Установка_Calculate_Linux_на_VMware.odt" \
                                  "report/Предпросмотр_отчёта_ЛР4.pdf"
```

Весь текст отчёта, таблицы и подписи к рисункам находятся в `build/content.py`;
параметры страницы, шрифтов, ширины рисунков — в начале `build/make_report.py`
(там же параметр `img_min_dpi`, ограничивающий растягивание мелких скриншотов
диалоговых окон).

Сборка не требует LibreOffice и Microsoft Office: ODT формируется библиотекой
`odfpy`. Номера страниц в СОДЕРЖАНИИ рассчитаны моделью разметки
(`build/paginate.py`) и записаны в файл одновременно и как обычный текст, и как
поле-перекрёстная ссылка на закладку — при открытии отчёта в LibreOffice номера
пересчитаются автоматически («Сервис → Обновить → Обновить всё»).

## Предпросмотр

`report/Предпросмотр_отчёта_ЛР4.pdf` — изображение вёрстки, построенное той же
моделью разметки (шрифт Tinos метрически совпадает с Times New Roman). Файл
нужен только для быстрой проверки отчёта; сдаётся файл `.odt`.
