# Лабораторная работа № 3. Настройка загрузчика GRUB2

Отчёт о выполнении лабораторной работы по дисциплине «Операционные системы и среды»:
изучение процесса загрузки Linux, исследование конфигурации загрузчика GRUB2,
добавление собственного пункта меню (режим восстановления) и изменение параметров ядра.

Работа выполнялась на виртуальной машине VMware Workstation с операционной системой
**«РОСА Фреш» 13.2** (ядро 6.12.74-generic-2rosa13-x86_64). Дистрибутив относится
к семейству Red Hat, поэтому в нём используется команда `grub2-mkconfig` и файл
`/boot/grub2/grub.cfg` (в Debian, Ubuntu и Astra Linux — `update-grub`
и `/boot/grub/grub.cfg`).

Оформление — по «Краткой выписке из ГОСТ 7.32-2017» (файл
`lab-01/examples/ОформлениеОтчета_Краткая_выписка_из_ГОСТ_с_Примерами.pdf`):
Times New Roman 14 пт, полуторный интервал, выравнивание по ширине, абзацный
отступ 1,25 см, поля 30/15/20/20 мм, номера страниц внизу по центру (титульный лист
без номера), заголовки подразделов разрежены на 3 пт, подпись рисунка — под
рисунком по центру, название таблицы — слева над таблицей, выводы команд —
моноширинным шрифтом Courier New 10 пт.

## Состав отчёта

1. Титульный лист
2. РЕФЕРАТ — число страниц, рисунков, таблиц, источников и ключевые слова
3. СОДЕРЖАНИЕ — с номерами страниц и отточием
4. 1 Цель работы
5. 2 Краткие теоретические сведения
6. 3 Используемое окружение (дистрибутив и версия, версия ядра, тип виртуальной
   машины — таблица 1)
7. 4 Ход выполнения работы:
   - 4.1 Задание 0. Определение дистрибутива и структуры загрузки
     (рисунки 1–5, таблица 2 — разделы диска);
   - 4.2 Задание 1. Исследование текущей конфигурации GRUB (рисунки 6–9);
   - 4.3 Задание 2. Добавление нового пункта меню в GRUB
     (рисунки 10–14, таблица 3 — подставленные значения);
   - 4.4 Задание 3. Изменение параметров ядра (рисунки 15–18);
8. 5 Ответы на контрольные вопросы (вопросы 1–6)
9. 6 Вывод по работе (включая таблицу 4 — сравнение команд Astra Linux и «РОСА»)
10. СПИСОК ИСПОЛЬЗОВАННЫХ ИСТОЧНИКОВ (8 источников, на каждый есть ссылка [n])

Рисунки 1–18 — скриншоты из `screenshots/`, выводы команд — из `outputs/`
(каждый вывод приведён в отчёте текстом, моноширинным шрифтом).
Каждый структурный элемент начинается с нового листа; рисунки пронумерованы
сквозной нумерацией, подпись — под рисунком; название таблицы — слева над таблицей.

## Пересборка

```bash
python3 -m venv .venv && .venv/bin/pip install -r build/requirements.txt
.venv/bin/python build/make_report.py     # собрать ODT и рассчитать номера страниц
.venv/bin/python build/preview.py "report/Отчёт_ЛР3_Настройка_загрузчика_GRUB2.odt" \
                                  "report/Предпросмотр_отчёта_ЛР3.pdf"
```

Весь текст отчёта, таблицы и подписи к рисункам находятся в `build/content.py`;
параметры страницы, шрифтов и ширины рисунков — в начале `build/make_report.py`.
Выводы команд подставляются из `outputs/N.txt` без изменений.

Сборка не требует LibreOffice и Microsoft Office: ODT формируется библиотекой
`odfpy`. Номера страниц в СОДЕРЖАНИИ рассчитаны моделью разметки
(`build/paginate.py`, калибровка по реальным документам LibreOffice) и записаны
в файл одновременно и как обычный текст, и как поле-перекрёстная ссылка на
закладку — при открытии отчёта в LibreOffice номера пересчитаются автоматически
(«Сервис → Обновить → Обновить всё»).

## Предпросмотр

`report/Предпросмотр_отчёта_ЛР3.pdf` — изображение вёрстки, построенное той же
моделью разметки (шрифт Tinos метрически совпадает с Times New Roman).
Файл нужен только для быстрой проверки отчёта; сдаётся файл `.odt`.
